# 간 검사 이상 에이전트 화면

EMR 안에서 에이전트 네 개와 질의응답이 시간 흐름에 따라 작동하는 모습을 보여 주는 정적 웹 화면입니다 (KCD 2026 포스터용). 환자와 기록은 모두 손으로 만든 가상 자료입니다 (시연 사례 5명, 아래 표). 에이전트 출력은 MIMIC 연구원의 모델 패키지 (MIMIC-IV 학습, 고정) 를 이 가상 사례에 그대로 적용한 결과이고 (`npm run models`), 지식 근거는 근거 위키 (`../wiki_kb`, 원문 13편으로 만든 한국어 위키) 에서 가져옵니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성 (GitHub Pages 에 올릴 것)
npm run wiki     # ../wiki_kb 가 바뀌면 public/wiki/kb.json 을 다시 만듦
```

화면은 1280px 이상 데스크톱 기준입니다 (1920x1080, 1440x900 에서 확인).

## 정의 (MIMIC 명세서 기준, 10/17 결정)

| 항목 | 정의 |
|---|---|
| 공개 시각 | max(채혈 시각, 보고 시각). 화면과 에이전트는 기준 시각까지 공개된 기록만 봄. 사건의 t0 도 공개 시각 |
| ULN | 그 행의 기록 상한 |
| 대상 | ICU 입실 전 같은 입원에서 이미 2배 이상이던 환자는 제외 |
| 첫 이상 | ALT, ALP, 총빌리 중 하나가 2 x ULN 이상 (OR). 정상 구간이 끝나 발생 예측이 멈춤 |
| 5배 사건 | ALT, ALP, 총빌리 중 하나가 5 x ULN 이상 (OR). 발생 예측의 목표이고, 종료 상태와 원인 추정이 이때 한 번 돎 (10/17 결정, 패키지는 첫 이상 시점) |
| 회복 | ICU 퇴실 때 마지막 ALT, ALP, 총빌리가 모두 2 x ULN 미만. 5배 사건 뒤 다시 재지 않으면 판정 불가 |
| 사망 | ICU 사망 (퇴실 뒤 24시간 안 포함) |
| 정상 구간 | ALT, ALP, 총빌리를 모두 최근 24시간 안에 쟀고 모두 2배 미만. 발생 예측은 이때만 내고 아니면 판정 불가 |

모든 정의와 상수는 `src/lib/events.ts` 에 있습니다. 바탕 문서는 `docs/liver_agent_7site_summary.md` 입니다 (공개 저장소에는 올리지 않음).

## 화면 흐름

위쪽 재생 버튼을 누르면 ICU 입실부터 퇴실까지 한 시간씩 넘어갑니다. 시간선을 누르거나 끌어도 기준 시각이 바뀝니다.

폭 1100px 이하 (폰, 세로 태블릿) 에서는 패널을 세로로 쌓고, 환자 고르기 상자와 'AI 에이전트 | 진료 기록' 전환으로 봅니다. 'PC 화면으로 보기' 를 누르면 데스크톱 화면을 줄여서 보여 주고 (손가락으로 확대), '모바일 화면으로' 로 돌아옵니다 (`src/lib/viewport.ts`).

오른쪽 위 **한국어 | English** 버튼으로 화면 언어를 바꿉니다 (`?lang=en` 으로 바로 열 수도 있고, 고른 언어는 브라우저에 기억됨). 근거 위키 본문과 검색은 한국어 그대로이고, 영어 화면의 지식 질문 버튼은 한국어 질문으로 검색합니다.

| 에이전트 | 도는 시점 | 출력 | 모델 (패키지 파일) |
|---|---|---|---|
| 1 발생 예측 | 첫 이상 전 매시간 (정상 구간만) | 24시간 안 5배 사건 확률, 변수 묶음별 기여 (그룹 Shapley), 경보 (30%, 화면 설정). 멈춘 뒤 24시간 안 5배 사건으로 정답 확인 | 그래디언트 부스팅 `agent3_gbm.joblib` |
| 2 종료 상태 | 5배 사건 때 한 번 | 회복 여부 x ICU 사망 여부 4경로 확률, ICU 사망 확률 (별도 모델), 모델이 본 주요 입력 | `prognosis_gbm.joblib` (첫 이상 시점 자료로 학습. 5배 시점 적용은 학습한 시점과 다름) |
| 3 원인 추정 | 5배 사건 때 한 번 | 원인 범주 10개마다 규칙 점수와 규칙이 인용한 근거, 근거 위키의 진단 기준과 근거 공백. 1.0 이상이면 해당 (여러 개 가능), 담낭염은 판단 불가. 간 패턴 군집은 보조 정보로만 표시 | 규칙 기준 모델 `rule_agent.py` (학습 없음), 군집 `cluster_models.joblib` |
| 4 24시간 궤적 | 첫 간 검사 결과 뒤 매시간 | 6, 12, 18, 24시간 뒤 ALT, AST, ALP, 총빌리의 10%, 50%, 90% 값 (그 시각 24시간 안에 잰 항목만) | 분위 그래디언트 부스팅 `trajectory_qgbm.joblib` |
| 질의응답 | 물을 때 | 이 환자 질문은 기준 시각까지의 사례 자료와 에이전트 출력으로, 지식 질문은 근거 위키를 검색해 답하고 원문과 쪽수를 붙임. 근거가 없거나 치료 결정 질문이면 답하지 않음 | `qa.ts` (이 환자), `rag.ts` + 근거 위키 (지식), 답 생성 서버 (선택) |

재생 중에는 첫 경보, 첫 이상, 5배 사건, 퇴실 시점에서 멈추고 그 에이전트를 보여 줍니다. 5배 사건 때는 원인 추정이 단계별로 실행되는 모습을 보여 줍니다.

## 불확실성 표시 (불확실성 구현 명세와 불확실성 기획안 10/17)

모델은 다시 학습하지 않고, 모델 패키지 출력 위에서 미리 고정한 규칙으로 계산합니다. 기준값은 모두 `src/lib/uncertainty.ts` 에 있습니다.

| 에이전트 | 표시 | 계산 |
|---|---|---|
| 1 발생 예측 | 확신 (높음, 낮음) 과 이유, 구간, 줄이는 검사, 심각도 사다리, 위험을 올린 근거 상위 2개, 대상 아님 사유 | 아래 확신 규칙 1~5. 구간은 24시간 안에 재지 않은 핵심 입력의 변수 묶음을 기준 행 10개 (개발 집단 백분위) 로 바꿔 넣고, 잰 핵심 입력은 검사 오차 범위 (±10%) 안에서 흔든 (최근 값과 24시간 변화를 같은 양만큼, 항목마다 따로 섞은 10칸 격자) 예측의 10~90% (기획안 4-2). 확률이 구간 밖일 수 있음 (모델이 '재지 않음' 자체나 경계값에 민감할 때). 사다리는 같은 입력으로 `agent3_gbm_2x/3x/4x` (5배는 발생 예측 모델과 같은 모델) |
| 2 종료 상태 | 경로 집합 ('이 중 하나일 가능성이 높음'), 확신 (규칙 6), 회복 판정에 필요한 검사 | 경로 집합은 확률이 7.9% 이상인 경로 (`PATH_MIN_PROB`). MIMIC 평가 집단 반에서 실제 경로를 90% 담도록 정한 conformal 기준 (LAC), 나머지 반에서 88.7% 를 담음 (`uncertainty/stage3.py`) |
| 3 원인 추정 | 범주마다 근거 자료 완성도 (있음 / 필요), 자료 상태 (있음, 측정 없음, 연결 안 됨, 자료에 없음, 이전 입원 없음), 판정 취약, 판단 보류 | 판정 취약은 규칙이 읽은 검사값 (와 48시간 혈색소 감소) 을 하나씩 ±10% 바꿔 규칙을 다시 돌렸을 때 0/1 이 바뀌는지 (`run_models.py`). 판단 보류는 원인 약이 둘 이상이거나 예방 목적 투여 (DILI), 저관류가 있지만 AST·ALT 가 3~5×ULN (저산소성 간염) |
| 4 궤적 | 10~90% 띠 (conformal 로 넓힘), 최근 24시간 측정 없는 항목은 '예측 안 함', 이 병원 포함률은 확인 전이라는 안내 | 패키지 출력의 띠를 검사와 예측 시점마다 2^w 배 넓힘 (`TRAJ_WIDEN`, CQR). MIMIC 원래 포함률 70.5~77.1% → 77.5~82.3% |
| 공통 | 보고 대기, 회복 판정에 필요한 검사, 사건 경계값, 병원 공지 | 채혈 ≤ 지금 < 보고인 검사 / 5배 사건 뒤 다시 재지 않은 사건 항목 (일부만 다시 쟀거나 24시간이 지났을 때) / 사건 값이 기준의 ±10% 안 / 연결부가 넘기지 않는 자료 (영상 판독문 등) |

| 확신 규칙 | 기준 |
|---|---|
| 1 핵심 입력 결측 | 간 검사 4개, INR, 젖산, 크레아티닌 중 2개 이상이 24시간 안 측정 없음 |
| 2 MIMIC 범위 밖 | 주요 변수 22개가 개발 집단 (조기 예측 대상 시간) 의 5~95% 밖. 기준은 모델 파일의 기준 행에서 읽음 (`meta.reference`) |
| 3 입력 오류 보류 | 패키지 입력 오류 검사 (`data_errors.guard_lab`, 활력징후·나이 범위) 에서 보류된 값이 있음. 보류된 값도 모델 입력에서는 빼지 않음 |
| 4 구간이 넓음 | 구간 폭 1.13%p 이상 (MIMIC 개발 집단 표본의 상위 25% 폭, `uncertainty/stage1.py`) |
| 5 사다리 뒤집힘 | 높은 배수 확률이 바로 아래 배수 확률보다 큼 (`LADDER_TOL` 0) |
| 6 예후 경로 집합 | 경로가 둘 이상 (예후 카드에만) |

- 검사 오차 범위 10% (`ERROR_RANGE`) 는 임상의 선생님 확인 전 임시값입니다. 규칙 4 폭 기준, 경로 집합 기준, 궤적 띠 넓힘은 로컬 MIMIC 에서 기획안 정의대로 정한 값입니다 (10/17).
- 예후와 원인 입력의 MIMIC 범위 기준 (첫 이상 시점 백분위) 은 아직 없어 '처음 보는 수준의 값' 안내는 하지 않습니다.
- 과거력, 합토글로빈, NT-proBNP, 간염 혈청 검사 (`serology`) 는 연결부가 넘깁니다. 영상 판독문은 자료에 없어 병원 공지로 띄웁니다.

## 구성

| 위치 | 내용 |
|---|---|
| `src/types.ts` | 자료 형식. 사례 자료, 사건, 에이전트 출력 (`A1Point`, `A2Output`, `A4Forecast`, `AgentRun`, `CauseCall`, `ModelOutputs`), 질의응답 (`QaMsg`) |
| `src/lib/events.ts` | 정의와 상수. 공개 시각, 사건 찾기, 정상 구간, 퇴실 때 판정, 기준 시각에 보이는 기록 |
| `src/data/cases/` | 시연 사례 5명 (`c1.ts` ~ `c5.ts`) 과 공통 도구 `kit.ts`. 입실 전 응급실·병동 검사부터 퇴실까지 검사, 투약, 활력징후, 배양, 처치, 과거력 |
| `src/data/runs.ts` | 사례마다 원인 추정 실행 기록: 패키지 원인 규칙 출력 + 근거 위키 지침 근거 + 도구 호출 단계 + 근거 자료 완성도, 판정 취약, 판단 보류 |
| `src/lib/i18n.ts`, `src/data/cases/en.ts` | 화면 언어. 문구는 쓰는 자리에서 `tr('한국어', 'English')`, 모듈 상수는 `bi()` + `pick()`. 사례 자료 문구는 화면에 보일 때만 `tx()` 로 영어로 바꿈 (판정 로직은 한국어 자료 그대로) |
| `src/lib/uncertainty.ts` | 불확실성 규칙과 기준값: 확신 규칙 1~6, 경로 집합, 보고 대기, 사건 경계값, 근거 자료 완성도, 병원 공지 |
| `src/data/modelrun.ts`, `src/data/model/` | 모델 패키지 적용 출력과 화면 형식 변환 |

## 모델 패키지 적용 (`npm run models`)

MIMIC 연구원의 모델 패키지 (`../kcd_model_package_*`, 공개 저장소에는 올리지 않음) 를 가상 사례에 다시 학습 없이 적용합니다.

1. `model-bridge/export-case.ts`: 가상 사례를 패키지 검사 이름 (TBIL, CREAT 등) 과 공개 시각으로 내보냄
2. `model-bridge/run_models.py`: 패키지의 중간 표 모양 (cohort, lab, context, events) 으로 바꾼 뒤 패키지 함수를 그대로 부름. 변수 계산 `build_features`, 설명 `explain_rows`, 궤적 `forecast_rows`, 원인 규칙 `rule_agent1`, 군집 `assign_clusters`, 입력 오류 검사 `guard_lab`. 불확실성 (사다리, 구간, 범위 밖 입력, 판정 취약) 도 여기서 계산
3. 결과 `src/data/model/c1.json` ~ `c5.json` (환자 식별 번호 없음) 을 `src/data/modelrun.ts` 가 화면 형식으로 바꿈

```bash
# MODEL_CARD.md 와 같은 버전이 필요합니다: python 3.11, scikit-learn 1.9.0, pandas 2.3.3, numpy 2.4.6
uv venv --python 3.11 .venv-models && uv pip install --python .venv-models/bin/python scikit-learn==1.9.0 pandas==2.3.3 numpy==2.4.6 joblib
KCD_PYTHON=.venv-models/bin/python npm run models     # 패키지 위치가 다르면 KCD_MODEL_PACKAGE=<폴더>
```

- 화면 정의와 모델 출력의 5배 사건 시각이 다르면 원인 추정이 비고 콘솔에 오류가 납니다 (사례를 바꾸면 다시 실행).
- 종료 상태와 원인 추정은 5배 사건 시점 기록으로 돌립니다 (`run_models.py` 의 `target_event`). 패키지는 첫 이상 시점이고, 예후 모델도 그 시점 자료로 학습했습니다.
- 발생 예측과 궤적은 입실 시각부터 돕니다. 같은 입원의 입실 전 응급실·병동 검사도 입력에 들어가기 때문입니다 (MODEL_CARD).
- 과거력 (`history`) 은 이전 입원의 진단 코드로 넘기고, 패키지의 `history_flags` 가 6가지 과거력으로 바꿉니다.
- 패키지에 경보 운영 기준이 없어 발생 예측 경보 30% 는 화면 설정입니다 (`src/lib/events.ts` 의 `A1_THRESHOLD`).
- 임상 표현형 군집은 개발 때 불안정 (부트스트랩 ARI 0.75 미만) 이라 패키지 규칙대로 쓰지 않습니다.
- 2·3·4배 모델 (`agent3_gbm_2x` 등) 은 심각도 사다리에만 씁니다. 48시간 경로 모델 (`agent2_gbm`) 은 화면에 쓰지 않습니다.
- 모델 출력이 없는 새 사례는 에이전트 1, 4 에 대체 계산 (`standin.ts`) 을 씁니다.

## 질의응답과 근거 위키 (RAG)

**검색 (서버 없이, GitHub Pages 에서도 됨)**
- `../wiki_kb` 는 원문 13편으로 만든 llm_wiki 형식의 한국어 위키입니다 (페이지 63, 조각 451). 문장마다 원문과 PDF 쪽수가 붙어 있습니다.
- `npm run wiki` 가 위키 페이지와 검색 조각을 `public/wiki/kb.json` 하나로 묶습니다. 원문 PDF (`wiki_kb/raw/`) 는 저작권 때문에 넣지 않고 git 에서도 뺍니다.
- 브라우저가 이 파일을 받아 BM25 로 검색합니다 (wiki_kb 색인과 같은 k1 1.5, b 0.75, 한글 두 글자). 원래 색인 스크립트는 받지 못해 토큰 나누기는 새로 짰고, 한국어 질문을 위키 표기 (영문 약물명 등) 로 넓히는 낱말표가 `src/lib/wiki.ts` 에 있습니다.
- 서버가 없으면 찾은 조각 3개를 그대로 보여 줍니다. 점수가 낮으면 '근거 약함', 맞는 조각이 없으면 답하지 않습니다.

**답 생성 (선택, 서버 필요)**
- 찾은 조각과 질문을 서버로 보내면 LLM 이 그 조각 안에서만 답을 쓰고, 서버가 인용을 확인합니다 (문장마다 조각 번호, 숫자가 인용한 조각에 그대로 있는지).
- LLM 은 OpenAI 호환 주소면 무엇이든 됩니다. 실제 자료에는 기관 승인 무보존 엔드포인트만 씁니다. 키는 환경 변수로만 넣습니다.

```bash
LLM_BASE_URL=<OpenAI 호환 주소>/v1 LLM_MODEL=<모델> LLM_API_KEY=<키> npm run rag-server   # http://127.0.0.1:8787
# 화면을 http://localhost:5173/?rag=http://localhost:8787 로 한 번 열면 기억합니다. ?rag=off 로 끔
```

GitHub Pages 화면에서 이 컴퓨터의 서버를 부르면 크롬이 로컬 네트워크 접근을 물을 수 있습니다 (허용하면 됨).

**원인 추정의 지침 근거**: `runs.ts` 의 범주별 지침 근거는 위키의 '원인 10개 근거 지도' 문장을 그대로 옮긴 것입니다. 누르면 위키의 그 절이 열립니다.
